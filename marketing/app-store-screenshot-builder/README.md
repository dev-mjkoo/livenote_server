# Screenshot Template Studio

앱스토어·프로모션용 세로 스크린샷을 반복 제작하는 로컬 HTML 도구입니다. 업로드한 원본 이미지를 Canvas에 직접 합성하며 외부 라이브러리나 생성형 이미지 처리를 사용하지 않습니다.

## 실행

프로젝트 루트에서 실행합니다.

```bash
python3 -m http.server 8787 --directory marketing/app-store-screenshot-builder
```

브라우저에서 `http://localhost:8787`을 엽니다.

이 폴더가 원본 소스입니다. 수정 후 배포 경로인 `docs/screenshot-studio`와
로컬 서버 경로인 `public/screenshot-studio`에 반영하려면 다음을 실행합니다.

```bash
npm run sync:screenshot-studio
```

## 기능

- 최대 10개 아트보드 추가·복제·삭제·순서 변경
- 언어 또는 국가를 추가하면 기본 언어의 전체 화면 세트를 새 행으로 복제
- 추가한 언어 행 삭제
- 화면 추가·복제·순서 변경·삭제를 모든 언어 행에 동일하게 반영
- 선택한 화면의 모든 언어 문구를 한 패널에서 빠르게 입력
- 한국어 화면을 기준으로 템플릿·목업·폰트·위치·배경 설정을 모든 언어에 자동 동기화
- 앱 화면 이미지는 언어별로 각각 업로드하고 독립적으로 유지
- 시그니처 블루·미니멀 페이퍼·블랙 에디토리얼·오로라 등 완성형 디자인 템플릿 12종
- 각 아트보드에 PNG·JPG 앱 화면 업로드 또는 드래그 앤 드롭
- 내장 Pretendard Variable 글꼴과 100~900 문구 굵기 설정
- 메인/보조 문구, 크기, 위치, 정렬, 색상 설정
- 앱 화면 크기와 세로 위치, 더 둥근 티타늄 색상별 아이폰 목업 설정
- 목업 세로 위치를 -2800px부터 2800px까지 자유롭게 이동
- 문구 세로 위치를 -1200px부터 3000px까지 자유롭게 이동
- 크기·위치·글자 굵기 값을 슬라이더와 숫자 입력으로 함께 조절
- Dynamic Island 표시·숨김 설정
- 직접 업로드하고 원형으로 자동 마스킹되는 로고 이미지와 크기·위치 설정
- 사선·3색 그라디언트·단색·다크 글로우·그리드·오로라·메시·스포트라이트·웨이브·스트라이프·링·컬러 분할 배경
- 기본색을 유지하며 보조색·포인트색을 추천하는 랜덤 배색 버튼
- 배경색과 별도 배경 이미지 지정
- 4가지 App Store 출력 규격
- 개별 PNG 또는 전체 PNG 저장
- 현재 프로젝트와 업로드 이미지를 브라우저 데이터베이스에 자동 저장
- 프로젝트 전체를 JSON 파일로 백업하고 다시 불러오기

초기 상태에는 LiveNote 화면 5장이 예시로 들어 있습니다. 이미지를 교체하면 다음 업데이트나 다른 앱에도 같은 템플릿을 재사용할 수 있습니다.
